# Einstieg und Gegenstand

`Local_Star` wird auf Repository-Ebene als eigenständiges mathematisches Topic neben `Foundation` angelegt. Es behandelt lokale **ausgehende** Sterne an beliebigen Wortadressen, deren gemeinsame Knoten, elementare Netzwerkenergie, vollständige DtN-Randfamilien, Widerstandsgeometrie und die mathematisch kontrollierbare Kopplung endlicher Sternblöcke. Der Code aus dem früheren `FloatingStar`-Projekt wird weder importiert noch abgeschrieben.

**Unbedingt unterscheiden:** Einheitslänge der primitiven Foundation-Kante, explizite Wahl elektrischer Einheitsleitfähigkeit, daraus *bewiesener* effektiver Einheitswiderstand, positive semidefinite Laplace-/DtN-Form, positiv definite geerdete Energie und die wurzelbezogene **Einheits-Gram-Matrix** aus Widerständen.

Die unendliche Strahlgrenze und die gemeinsam kurzgeschlossene Tiefengrenze sind verschiedene Objekte. Längs eines einzelnen Strahls wächst der Widerstand ohne Schranke; zum gemeinsam kontaktierten Rand kann der Grenzwiderstand für `b ≥ 2` endlich sein.
