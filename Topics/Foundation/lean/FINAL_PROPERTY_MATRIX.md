# FINAL PROPERTY MATRIX — `TreeN`, `TreeZ`, `TreeQ`, `TreeR`

One row per specific property. Status vocabulary (mutually exclusive):
`PROVED_UNCONDITIONALLY`, `PROVED_CONDITIONALLY`, `PROVED_OBSTRUCTION`, `OPEN`,
`NOT_APPLICABLE`, `DEFINITION_ONLY`.

* A row marked `PROVED_UNCONDITIONALLY` whose statement is an equivalence `P ↔ Principle` proves
  the **equivalence**; the substantive target `P` then has its own row, marked
  `PROVED_CONDITIONALLY` or `OPEN`.
* `[TwoLetters α]` is a typing premise of the carrier `TreeQ α` as a field (the two distinguished
  letters needed by the witness construction), not an extra mathematical hypothesis. It is
  listed for transparency.
* The *axiom audit* column is the union of the `#print axioms` results of the cited declarations,
  copied mechanically from `Audit/axioms_task04.txt`. `Classical.choice` occurs nowhere.
* Interface lemmas (`TOField.*`, `TField.*`, `CSR.*`) count for a carrier only through the
  concrete instances `TreeN.instCSR`, `TreeZ.instCRing`, `TreeQ.instTField`, `TreeQ.instTOField`
  and `TreeR.instCRing`. Each field of these instances is a named concrete theorem; see
  `TASK04_BASELINE.md` §2.
